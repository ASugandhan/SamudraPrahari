## Deliverables
- `preprocess/tiling.py::tile_image` — 640 px tiles, 20% overlap, last tile flush to edge;
  each `Tile` stores `row_off/col_off` + cropped `valid_mask`; `min_valid_frac` skips near-empty
  tiles. Round-trip is exact by construction.
- `preprocess/pipeline.py::run` — the ONLY public function (R8). Fixed `STEP_ORDER`
  bottom→slant→nadir→gain→despeckle→contrast→quality→tiling; each step toggleable via
  `enabled`, order immutable. `--save-steps` writes one PNG per step.

## Deviations / honest notes
- **Quality/tiling ordering**: per-tile quality needs tiles, but the document lists
  quality→tiling. Resolved faithfully: the `quality` step creates the tile geometry and
  flags each tile ("gate flags low tiles"), and `tiling` emits that (already-flagged) list —
  so the recorded order stays quality→tiling and tiles carry `quality_flag`. If quality is
  disabled, `tiling` builds the tiles itself. No duplicate tiler.
- 4000×2000 timing is on a random-noise image (real surveys similar cost; dominated by
  `gain` FFT + `quality` Canny). CPU: local dev box.
