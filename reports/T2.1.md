## But the acceptance gate (AUROC ≥ 0.80) is NOT met
Tile-level AUROC, object-free (normal_seabed test, n=30) vs object tiles, by score type:
```
                     origin   mean   max    p99
ai4                  REAL     1.00   1.00   1.00
sctd                 REAL     0.78   0.91   0.90
pure_synth_subpipe   synth    0.30   0.66   0.70
pure_synth_uatd      synth    0.36   0.73   0.77
synth_net            synth    0.45   0.72   0.60
ALL objects                   0.51   0.77   0.76
```
Two findings:
1. **The stated "mean anomaly score" is a poor aggregator** (0.51 — it dilutes small localized
   anomalies over a 640² tile). **max/p99 recover it to 0.77** — still < 0.80, but far better.
   Recommend max/p99 for the anomaly path (and for T2.4 fusion).
2. **Sim-to-real confound (R4).** The AE was trained on SYNTHETIC seabed only, so it mostly
   detects "is this real sonar (unlike training)?" not "is there an object?": REAL sources
   score ~1.0 everywhere (whole image out-of-distribution), while SYNTHETIC objects on
   in-distribution background only reach 0.66–0.73 (max). The 1.0 on ai4/sctd is domain shift,
   not object detection. (Caveat: negatives n=30, ai4 positives n=12 — the per-source AUROCs,
   especially ai4=1.00, are noisy at this size; the direction is clear, the exact values aren't.)
