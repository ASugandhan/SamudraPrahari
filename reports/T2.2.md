## Honest reading (this is the important part)
- **Real recall (ai4 1.0, sctd 0.90) is inflated by the sim-to-real confound.** Real sonar is
  out-of-distribution for the synthetic-trained AE, so the *whole* real image reads as anomalous
  (ai4 AUROC = 1.0 even without objects). The object gets hit because everything does.
- **Synthetic recall (0.60–0.78) is the more honest object-detection signal** — there the
  background matches training, so only real object regions should fire. It's below 0.80.
- **FC/image ~19–24 everywhere** — Stage-A anomaly alone is noisy. This is expected; the box
  is `origin="anomaly"` candidates feed the UNKNOWN pool, and T3.3 shadow verification + T2.4
  fusion with YOLO cut this downstream. But as a standalone screen it over-fires.
- Compared with the collapsed model, the fix **flipped** the pattern (real now high, synthetic
  moderate) — evidence the AE now responds to reconstruction difficulty, not a constant output.
